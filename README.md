# Motion For Svelte

This is an attempt to bring a Motion (formerly known as Framer Motion) to Svelte.

# Documentation

Read the docs at **[motion.hyprsonic.dev](https://motion.hyprsonic.dev)**. The site lives in [`docs/`](./docs); run it locally with `bun install` and `bun run docs`.

## Quick Start

```bash
npm install motion-sv
```

Then import the `motion` component:

```svelte
<script lang="ts">
	import { motion } from "motion-sv";
</script>

<motion.div animate={{ x: 100 }}>Hello</motion.div>
```

## Key Differences from Motion for React and Vue

Most of the API is identical. The main differences:

- **Layout animations** need to know which state the layout depends on, because Svelte has no hook that runs before the
  DOM updates. Render the elements through a namespace from `createLayoutMotion()`, with a getter for that state, or call
  its `update()` with the state change. Shared layout animations with `layoutId`, exits in `AnimatePresence` and
  `Reorder` lists work without it.

  ```svelte
  <script lang="ts">
  	import { createLayoutMotion } from "motion-sv";

  	let isOn = $state(false);
  	const layout = createLayoutMotion(() => isOn);
  </script>

  <button class={{ on: isOn }} onclick={() => (isOn = !isOn)}>
  	<layout.div class="handle" />
  </button>
  ```

- **`AnimatePresence`** works with Svelte's `{#if}`, `{#each}` and `{#key}` blocks.
- **Props**: `whilePress` instead of `whileTap`, `inViewOptions` instead of `viewport`, and `bind:ref` for the element.
- **Hooks** take getters for inputs that change, like elements bound after setup:
  `useScroll(() => ({ target: el }))`.

The documentation covers all of these in detail.
