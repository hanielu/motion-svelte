This project is an attempt to bring a Motion (formerly known as Framer Motion) to Svelte.

# General code style

- always use kebab-case for filenames for any files you create.
- always use svelte 5 syntax for any files you create.
- when coming up with solutions, always make sure the solution is the most elegant and efficient solution.
- make sure the solution follows common patterns and best practices like DRY principles, YAGNI principles, etc.
- Don't try to make things backwards compatible unless specifically requested.

# Other Rules

- this is a greenfield project, drastic overhauls/changes are allowed.
- don't create markdown or txt files unless explicitly asked to.
- don't create tests unless explicitly asked to.
- don't run any tests or lint commands unless explicitly asked to.
